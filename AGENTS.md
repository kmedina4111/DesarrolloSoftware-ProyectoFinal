# AGENTS.md

## Archivos estáticos

- Todo el código **CSS** va en `assets/css/` (ej. `assets/css/estudiantes.css`).
- Todo el código **JavaScript** va en `assets/js/` (ej. `assets/js/estudiantes.js`).
- No escribir CSS ni JS inline en los archivos `.php` (`<style>`, `<script>` con código, atributos `style=""` u `onclick=""`); enlazarlos con `<link>` y `<script src>`.
